  SISTEMA IRPC v3 — INSTRUÇÕES DE INSTALAÇÃO
════════════════════════════════════════════════════

PASSO A PASSO:

1. Extraia o arquivo irpc-app-v3.tar.gz na sua pasta de projetos

2. Abra o terminal dentro da pasta irpc-app-v3

3. Instale as dependências:
   npm install

4. Configure suas credenciais do Firebase em:
   src/lib/firebase.ts
   (substitua os valores "SUA_API_KEY" etc pelos dados do seu projeto)

5. Rode o projeto:
   npm run dev

6. Acesse no navegador:
   http://localhost:5173

════════════════════════════════════════════════════
  REGRAS FIRESTORE
════════════════════════════════════════════════════

Após o deploy, publique o arquivo firestore.rules no
Firebase Console → Firestore → Regras.

Isso corrige a vulnerabilidade de segurança onde qualquer
usuário autenticado poderia ler dados de outros usuários.
